<h1>LIBO: Library Management System</h1>
<p><strong>Enhancing Library Operations</strong></p>

<p>Ever wondered how technology can simplify book borrowing and management? Our team at <strong>University of Colombo School of Computing</strong> proudly presents <strong>LIBO</strong>, a web-based platform designed to streamline library management!</p>

<p>As part of our Group Project, we tackled common challenges such as inefficient book tracking, manual borrowing systems, and cumbersome book management processes.</p>

<p><strong>LIBO</strong> streamlines library management with features like:</p>
<ul>
  <li>Online book reservations</li>
  <li>Easy tracking of borrowed books</li>
  <li>Efficient book maintenance (adding, editing, updating records)</li>
</ul>

<p>Built using <strong>MongoDB, Express.js, React.js, and Node.js (MERN Stack)</strong> with an <strong>MVC architecture</strong>, LIBO ensures usability, security, and scalability.</p>
